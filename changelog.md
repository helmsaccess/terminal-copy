# Version 0.1

- Added `NVDA+R` commands for setting and clearing review-cursor region marks.
- Added `NVDA+C` to copy the marked Windows Terminal region through UI Automation.
- Included available scrollback outside the visible viewport and support for marks set in either order.
- Removed outer whitespace-only lines and trailing whitespace, and shortened inner whitespace-only
  lines to empty lines.
- Prevented saved terminal regions from being read or copied after Windows is locked.
- Added a complete German interface translation and German installed help.
- Fixed German runtime announcements for setting the start and end marks.
- Changed the Terminal Copy license to GPL version 2 only.
